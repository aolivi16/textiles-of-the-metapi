# textiles-of-the-metapi
## METAPI Textile Collection
## Description
This project is meant to show the extent of the textile collection recorded in the MET API. The findings will show where these textiles come from, what type of fibers are most common, and show which fiber type (animal or plant) is common in which geographical area. The powerpoint housing the final project will also contain images of pieces from the collection gathered using python, the pandas library, matplotlib, and open refine. 
## Why
I am interested in weaving, and the history of textile production across the world. Textiles can be hard to preserve and maintain over time, but there are existing examples of textiles that are over 8,000 years old. Since the MET API is relatively easy to use and readily available, I thought that it could be interesting to pull the information from the API to see what the textiles in the MET are like. I am especially interested in the amount of plant versus animal fibers in the MET collection and would like to see what the numbers show. 
## Workflow
-Using Python Request library make calls from the MET API
-Use Pandas to create a dataset
-create a data frame and save dataset as a CSV
-Clean data using open refine 
-Create graphs from cleaned data 
## Further Uses
The python notebook attached to this project can be used by anyone to make calls on the MET API. Even in the textile category further refinement can be done  y changing one or more aspects of the query. The raw textile data could also be expanded upon, since I focused on pieces in the collection that were a majority textile like clothing and towels, and not items which have textiles in them like gun cases. The work could also be expanded to textile production itself, and it would be possible to pull textile information as well as information on tools like distaffs, drop spindles, or looms.
